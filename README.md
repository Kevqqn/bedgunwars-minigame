# BedGunWars Minigame

A Bedwars-style Minecraft minigame mod built for **Forge 1.20.1**

---

## Prerequisites

- **Java Development Kit 17** (JDK 17.0.2 recommended)
- **IntelliJ IDEA** (Community or Ultimate Edition)

---

## Setup in IntelliJ IDEA

### 1. Clone the Repository
```bash
git clone https://github.com/Kevqqn/bedgunwars-minigame.git
cd bedgunwars-minigame
